# Integrating the Civic Action Box with Deep Dives

**Last updated:** 2026-03-04

This documents how the civic action toolbox was added to the Heat & Harm deep dive, and what to do when adding it to future stories.

---

## Overview

The civic action box is generated by the [civic-action-builder](https://civic-action-builder.vercel.app/) tool. It produces self-contained HTML with inline styles. On the WordPress site, it's wrapped in a custom block (`wp-block-planet-detroit-civic-action`). On deep dive pages, we embed it directly with a float wrapper.

## Steps to add to a new deep dive story

### 1. Generate the HTML

Use the civic action builder to generate the HTML for the story. Copy the full `<div class="civic-action-box" ...>` output.

### 2. Wrap it in the float container

Place the civic action box HTML inside a wrapper div with class `civic-action-float`:

```html
<div class="civic-action-float">
  <div class="civic-action-box" style="background: #f0f5f8; ...">
    <!-- paste civic action builder output here -->
  </div>
</div>
```

### 3. Place it inside a `text-section`

The float wrapper must go **inside** a `<div class="text-section">`, before the first `<p>` tag of that section. The article text will wrap around it. Example:

```html
<div class="text-section reveal">
  <div class="civic-action-float">
    <div class="civic-action-box" style="...">
      <!-- civic action content -->
    </div>
  </div>
  <p>Article text wraps around the box...</p>
  <p>More article text...</p>
</div>
```

### 4. Add the JavaScript

Add the civic action JavaScript **inside the existing `<script>` block** at the bottom of the page (or as a separate script before `</body>`). It handles:

- GA4 event tracking when checkboxes are toggled
- The "Did you take action?" response form submission to the ask-planet-detroit API

The JS is the same every time — just the IIFE block starting with `(function() { ... })();` that calls `civicActionInit`.

### 5. Verify CORS (one-time setup, already done)

The ask-planet-detroit API (`/api/civic-responses`) must allow requests from the deep dives domain. `https://deepdives.planetdetroit.org` has already been added to the `ALLOWED_ORIGINS` list in `/Users/user/projects/ask-planet-detroit/api/main.py`. No action needed unless the domain changes.

## Required CSS

The following CSS must be in the story's `<style>` block. It's already present in the Heat & Harm story and should be copied to new stories:

```css
/* ============ CIVIC ACTION FLOAT ============ */
.civic-action-float {
  float: right;
  width: 350px;
  margin: 0.5rem -80px 1.5rem 2rem;
  position: relative;
  z-index: 10;
}
.civic-action-float .civic-action-box {
  box-shadow: 0 2px 12px rgba(0,0,0,0.08);
}
@media (max-width: 1100px) {
  .civic-action-float { margin-right: 0; }
}
@media (max-width: 768px) {
  .civic-action-float {
    float: none;
    width: 100%;
    max-width: 100%;
    margin: 1.5rem 0;
  }
  .civic-action-float .civic-action-box {
    max-width: 100% !important;
  }
}
```

**Key behavior:**
- Floats right, protrudes 80px into the right margin on wide screens
- Pulls back to text column edge on screens under 1100px
- Goes full-width stacked on mobile (under 768px)

## Critical CSS gotcha

The article body text uses `.text-section > p` (direct child selector) for font sizing at 1.3rem. The `>` is essential — without it, the 1.3rem bleeds into the civic action box's `<p>` tags and overrides their inline 14px sizing, making the box text way too large.

If you see oversized text in the civic action box, check that the CSS rule is:
```css
.text-section > p { ... }    /* CORRECT — direct children only */
```
Not:
```css
.text-section p { ... }      /* WRONG — cascades into nested elements */
```

## Gotchas and lessons learned

| Issue | Cause | Fix |
|-------|-------|-----|
| Form submits but nothing in Supabase | CORS blocking requests from deepdives.planetdetroit.org | Added domain to ALLOWED_ORIGINS in ask-planet-detroit API |
| Form shows "Thank you" even when blocked | JS uses `.catch(showThanks)` — shows success on failure too | By design (graceful degradation), but verify in Supabase |
| Civic action box text renders too large | `.text-section p` cascades into nested `<p>` tags | Use `.text-section > p` (direct child selector) |
| Box overlaps dark background sections | Float crosses section boundaries | Keep surrounding sections white, or end the float before a dark section |
